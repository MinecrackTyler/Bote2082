# Boscali Ocean Training Exercise: Expansion 2082 Compatibility

Compatibility pack for Expansion 2082, adding the Kairos class ekranoplan, Atrox class cruiser, Nekton class drone boat, and Mohawk class corvette as playable ships. Also adds the R6 and HASM-600 Axiom to relevant ships from the base mod. Currently does not add the Aethel class Carrier. 

Requires:
- [Blueprinter](https://github.com/nikkorap/NOBlueprinter-Releases) (2.1.2+)
- [Boscali Ocean Training Exercise](https://github.com/MinecrackTyler/BoscaliOceanTrainingExercise) (1.5.5+)
- [Expansion 2082](https://github.com/kingwixly/Expansion2082) (1.0.2+)
